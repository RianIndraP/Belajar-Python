Bab 1: Get Started

Python, tempat menulis Python, dan program yang menjalankan Python itu bukan hal yang sama.

Hal yang paling penting dipahami dari awal: Python, tempat menulis Python, dan program yang menjalankan Python bukan hal yang sama. Banyak pemula bingung karena mengira harus punya aplikasi khusus bernama "Python Editor". Untuk kondisi saat ini, Python 3.14.8 adalah rilis Python 3 stabil terbaru di Windows.

1. Apa itu Python?

Python adalah bahasa pemrograman. Bahasa pemrograman adalah bahasa yang kita gunakan untuk memberikan instruksi kepada komputer.

nama = "Rian"
print(nama)

Secara sederhana kita mengatakan:

Simpan "Rian" ke dalam variabel nama, kemudian tampilkan isinya.

Python dirancang dengan sintaks yang relatif mudah dibaca dan mendukung berbagai gaya pemrograman, termasuk procedural, object-oriented, dan functional programming. Dokumentasi resmi menjelaskan Python sebagai bahasa tingkat tinggi, memiliki dynamic typing, bersifat interpreted, dan digunakan untuk scripting sampai pengembangan aplikasi.

BidangContoh
Pemrograman dasarkalkulator, program latihan
WebDjango, Flask, FastAPI
Datapandas, NumPy
AI / Machine LearningPyTorch, TensorFlow
Automationotomatisasi file, Excel, browser
BackendAPI dan server
Desktopaplikasi GUI
Networknetworking dan tools
Scriptingmenjalankan pekerjaan otomatis

Python sendiri mempunyai standard library yang luas, dan ekosistemnya juga menyediakan banyak library pihak ketiga melalui Python Package Index (PyPI).

File hello.py hanya berisi kode Python. File tersebut belum melakukan apa-apa hanya karena kamu membuatnya. Yang menjalankannya adalah Python interpreter.

3. Jadi apa itu Python Interpreter?

Interpreter adalah program yang memahami dan menjalankan kode Python. Di Windows, setelah Python terpasang, biasanya bisa dijalankan melalui python atau py.

C:\Users\Rian> python
Python 3.14.8 ...
>>> 2 + 3
5
>>> nama = "Rian"
>>> print(nama)
Rian

Tanda >>> berarti kamu sedang berada di Python REPL: Read, Evaluate, Print, Loop.

4. Apakah Python harus punya "tempat khusus"?

Tidak. Ini salah satu hal terpenting. File Python bisa berada di folder biasa, misalnya D:\Belajar\Python\. Python tidak peduli project kamu berada di folder mana. Yang penting komputer mengetahui di mana Python interpreter berada.

5. Lalu kenapa orang menggunakan VS Code?

Karena VS Code bukan Python. VS Code adalah code editor.

Python       = bahasa
python.exe   = program yang menjalankan bahasa Python
VS Code      = tempat nyaman untuk menulis kode
Terminal     = tempat memberi perintah ke komputer

Microsoft menjelaskan ada tiga bagian terpisah:

VS Code + Python Extension + Python Interpreter

6. Apakah Python bisa dijalankan di VS Code?

Ya, sangat bisa. Pilih interpreter melalui Ctrl + Shift + P lalu Python: Select Interpreter. Setelah itu jalankan file dengan tombol Run Python File in Terminal, yang secara konsep menjalankan python hello.py.

Kamu menulis → hello.py → VS Code → Python Extension → Python Interpreter → Program berjalan

7. Bagaimana dengan Antigravity?

Bisa juga, dan ini relevan dengan setup yang kamu gunakan. Kamu dapat membuat file hello.py di editor Antigravity, dan Antigravity IDE menyediakan terminal sehingga kamu bisa menjalankan perintah secara lokal dengan python app.py.

Antigravity
├── Editor → hello.py
├── Agent
└── Terminal → python hello.py → Python Interpreter

Artinya: Antigravity tidak menjadi "Python". Python interpreter tetap menjadi bagian yang menjalankan kode.

8. Apakah berarti harus install Python walaupun sudah punya VS Code?

Ya, untuk menjalankan Python secara lokal pada dasarnya kamu perlu Python interpreter.

Install VS Code
↓ Install Python Extension
↓ Menulis print("Hello")
↓ Klik Run → Error

VS Code ≠ Python
Python Extension ≠ Python Interpreter

9. Bagaimana cara memasang Python di Windows?

Halaman resmi Python mencantumkan Latest Python 3 Release: Python 3.14.8 dan Python Install Manager 26.3 sebagai install manager Windows terbaru. Untuk belajar, gunakan Python 3.14.x stable, bukan release percobaan.

Python untuk Windows — halaman resmi

10. Setelah install, bagaimana mengecek Python?

python --version
py --version
py --list

python adalah perintah yang direkomendasikan untuk menjalankan Python, sedangkan py berguna terutama ketika terdapat beberapa versi Python pada komputer.

11. Sekarang kita benar-benar menjalankan Python

D:\BelajarPython\hello.py → print("Halo dunia!")

cd D:\BelajarPython
python hello.py
→ Halo dunia!

Tidak ada server. Tidak ada database. Tidak ada aplikasi khusus.

12. Apa bedanya python dan python hello.py?

python           = buka REPL
python hello.py  = jalankan file

13. Dua cara utama belajar menjalankan Python

Cara A — REPL

>>> 10 + 20
30
>>> print("Halo")
Halo
>>> nama = "Rian"
>>> nama
'Rian'

Bagus untuk mencoba hal kecil, tidak perlu membuat file.

Cara B — File .py

nama = "Rian"
umur = 18

print("Nama:", nama)
print("Umur:", umur)

Lebih cocok ketika program mulai panjang. Jalankan dengan python program.py.

14. Sebenarnya apa yang terjadi ketika python hello.py?

hello.py → Python Interpreter → Python Runtime → Instruksi dijalankan → Windows → Output

K.py adalah kode yang kamu tulis, sedangkan Python interpreter adalah mesin yang menjalankan kode tersebut.

15. Apakah file .py sama seperti .exe?

Tidak. hello.py adalah source code, sedangkan hello.exe adalah executable Windows.

.py → Python Interpreter → program berjalan

16. Apakah Python seperti PHP?

Karena kamu sudah belajar Laravel/PHP, perbandingan ini sangat membantu. Konsep dasarnya mirip: keduanya membutuhkan runtime yang memahami bahasa tersebut.

PHP:    index.php → PHP runtime       → program berjalan
Python: main.py   → Python interpreter → program berjalan

17. Apakah Python harus menggunakan VS Code?

Tidak. Python dapat dijalankan dari Command Prompt, PowerShell, Windows Terminal, VS Code, Antigravity, PyCharm, IDLE, Jupyter, dan Google Colab. Yang penting untuk eksekusi lokal adalah interpreter Python.

18. Bagaimana dengan Google Colab?

Di Google Colab, kamu dapat menulis dan menjalankan Python langsung dari browser. Alurnya bukan laptop ke Python lokal, melainkan:

Browser → Google Colab → Runtime Python di server Google → Output

Jadi untuk Colab, kamu tidak harus menginstal Python di komputer hanya untuk menjalankan kode di Colab. Untuk development lokal dengan VS Code/Antigravity, kamu tetap memerlukan interpreter lokal.

19. Jadi ada beberapa model menjalankan Python

Python lokal + terminal      → python program.py
Python lokal + VS Code       → VS Code memakai Python yang terpasang
Python lokal + Antigravity   → terminal menjalankan Python
Python cloud + Colab         → tanpa Python lokal

20. Lalu apa itu pip?

pip digunakan untuk memasang package Python.

python -m pip install requests
py -m pip install SomeProject
Python
├── Interpreter
├── Standard Library
└── Packages
      ├── requests
      ├── pandas
      ├── numpy
      └── ...

21. Lalu apa itu virtual environment?

.venv adalah lingkungan Python terisolasi untuk sebuah project. Kalau ProjectA membutuhkan requests dan pandas sementara ProjectB membutuhkan versi berbeda, kamu bisa memisahkannya.

python -m venv .venv
.venv\Scripts\activate

Untuk belajar Python dasar, belum wajib memikirkan .venv. Ketika mulai membuat project sungguhan, ini akan penting.

22. Jadi sebenarnya apa saja yang harus saya install?

1. Python
2. VS Code atau Antigravity
3. Extension Python (untuk VS Code/IDE yang memerlukannya)

Yang paling fundamental adalah Python Interpreter. Tanpa itu, editor lokal tidak punya mesin yang menjalankan Python.

23. Kalau sudah punya Antigravity, apakah masih perlu install Python?

Ya. Saat terminal menjalankan python hello.py, Windows tetap harus menemukan program Python. Antigravity membantu membuat dan mengelola kode; Python melakukan eksekusinya.

24. Mana yang perlu disiapkan?

Windows
├── Python 3.14.x
├── VS Code / Antigravity
└── folder project
     ├── .py files
     └── .venv       ← nanti

Workflow: buat folder, buat main.py, tulis Python, buka terminal, python main.py, lihat hasil. Urutan belajar: variabel, tipe data, if/else, loop, function, list/dict, file, module, pip, venv, OOP.

25. Contoh lengkap dari nol

  1. Install Python 3.14.x stable dari halaman resmi.
  2. Cek python --version di terminal.
  3. Buat folder D:\BelajarPython.
  4. Buat file hello.py berisi print("Halo, saya sedang belajar Python").
  5. cd D:\BelajarPython
  6. python hello.py → Halo, saya sedang belajar Python

27. Analogi paling gampang

Bayangkan kamu ingin memasak.

Python         = bahasa/resep
.py            = resep yang kamu tulis
Interpreter    = kokinya
Terminal       = tempat memberi perintah
VS Code        = meja dapur yang nyaman
Antigravity    = meja dapur + alat bantu AI
Package        = bahan/alat tambahan
venv           = kotak dapur khusus untuk satu masakan

Kamu tidak perlu dapur khusus bernama "Python". Yang penting ada "koki" yang memahami resep tersebut.
