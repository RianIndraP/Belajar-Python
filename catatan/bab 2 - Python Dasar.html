Bab 2: Variabel, Tipe Data, dan Cara Menyimpan Nilai

Variabel dan tipe data adalah dua konsep yang dipakai hampir di semua program Python. Memahaminya sebelum masuk ke if, loop, dan function akan membuat materi berikutnya jauh lebih ringan.

1. Apa itu variabel?

Variabel adalah nama yang digunakan untuk menyimpan sebuah nilai.

nama = "Rian"

Kita bisa membayangkannya sebagai kotak yang diberi nama:

┌─────────────┐
│ nama        │
│             │
│ "Rian"      │
└─────────────┘

Isinya diambil dengan menyebut namanya:

print(nama)   # Rian

Jadi nama = "Rian" berarti: buat variabel bernama nama, lalu simpan nilai "Rian" di dalamnya.

2. Kenapa kita membutuhkan variabel?

Tanpa variabel, program seperti ini harus diubah di banyak tempat:

print("Rian")
print("Rian")
print("Rian")

Dengan variabel, cukup ubah satu baris:

nama = "Rian"

print(nama)
print(nama)
print(nama)

Kalau namanya menjadi Andi, cukup nama = "Andi" dan semua print(nama) ikut berubah.

nama_variabel = nilai

4. Tanda = dalam Python

Saat kamu menulis umur = 18, tanda = berarti simpan nilai 18 ke variabel umur, bukan "sama dengan" seperti dalam matematika.

umur = 18   # dibaca: umur ← 18

5. Contoh sederhana

nama = "Rian"
umur = 18

print(nama)
print(umur)

Perhatikan bedanya dua penulisan ini:

print(nama)    # Rian   → Python mencari isi variabel nama
print("nama")  # nama   → Python memperlakukan ini teks biasa

6. Apa itu string?

Nilai "Rian" merupakan string, yaitu data berupa teks.

nama = "Rian"
kota = "Banda Aceh"
hobi = "Coding"

String bisa memakai kutip tunggal maupun ganda, keduanya sama-sama valid:

nama = "Rian"
nama = 'Rian'

7. Kenapa string menggunakan tanda kutip?

Karena Python perlu membedakan teks dan nama variabel.

nama = Rian     # Python mencari variabel bernama Rian → error
nama = "Rian"   # teks "Rian"

Rian dan "Rian" adalah dua hal yang berbeda bagi Python.

8. Tipe data int

int adalah singkatan dari integer, yaitu bilangan bulat. Nilainya ditulis tanpa tanda kutip:

umur = 18
jumlah = 10
saldo = 50000
tahun = 2026

Jika ditulis umur = "18", nilainya bukan integer melainkan string.

9. Perbedaan "18" dan 18

Ini salah satu konsep paling penting dalam pemrograman.

a = 18
b = "18"

print(type(a))   # <class 'int'>
print(type(b))   # <class 'str'>

Keduanya tampil sama, tetapi Python memperlakukannya berbeda:

a = 18
b = 2
print(a + b)     # 20  → penjumlahan angka

a = "18"
b = "2"
print(a + b)     # 182 → penggabungan teks

Operasi + pada dua string berarti menyambung, bukan menambah.

10. Tipe data float

Untuk bilangan desimal, tipe datanya float:

tinggi = 170.5
berat = 55.7
harga = 12500.50
phi = 3.14

11. Tiga tipe data utama sejauh ini

str   → teks
int   → bilangan bulat
float → bilangan desimal
nama = "Rian"     # str
umur = 18            # int
tinggi = 170.5       # float

12. Tipe data boolean

Tipe bool hanya punya dua nilai: True dan False.

is_student = True
is_married = False

Huruf besar di awal wajib dipakai. true dan false tidak valid.

13. Kenapa boolean penting?

Boolean dipakai terus-menerus saat belajar kondisi nanti:

is_logged_in = True

if is_logged_in:
    print("Selamat datang")

14. Cara mengetahui tipe data

Fungsi type() memeriksa tipe sebuah nilai:

nama = "Rian"
print(type(nama))     # <class 'str'>

umur = 18
print(type(umur))     # <class 'int'>

tinggi = 170.5
print(type(tinggi))   # <class 'float'>

aktif = True
print(type(aktif))    # <class 'bool'>

15. type() sebenarnya melakukan apa?

type(nama) berarti: "Data di dalam nama ini tipe apa?" Lalu print(type(nama)) menampilkan hasil pemeriksaan itu.

16. Variabel bisa diubah

umur = 18
print(umur)      # 18

umur = 19
print(umur)      # 19

Assignment terakhir menggantikan nilai sebelumnya:

nama = "Rian"
nama = "Andi"
nama = "Budi"

print(nama)      # Budi

17. Variabel bahkan bisa berubah tipe

Python memakai dynamic typing, yaitu tipe variabel mengikuti nilai yang diberikan terakhir.

data = 10
print(type(data))      # <class 'int'>

data = "Halo"
print(type(data))      # <class 'str'>

data = 3.14
print(type(data))      # <class 'float'>

Artinya, kita tidak perlu menulis tipe variabel secara eksplisit saat membuatnya.

18. Aturan penamaan variabel

Nama yang Valid:

nama = "Rian"
nama_depan = "Rian"
nilai1 = 90
nilai_akhir = 95

Tidak boleh diawali angka

1nama = "Rian"    # salah
nama1 = "Rian"    # benar

Tidak boleh memakai spasi

nama lengkap = "Rian Indra"     # salah
nama_lengkap = "Rian Indra"    # benar

Tidak boleh memakai keyword Python

if = 10    # salah, if adalah keyword

Daftar keyword yang tidak boleh dipakai antara lain: if, for, while, class, def, return.

19. Python membedakan huruf besar dan kecil

Python bersifat case-sensitive, jadi tiga nama berikut dianggap berbeda:

nama = "Rian"
Nama = "Andi"
NAMA = "Budi"
nama = "Rian"
print(Nama)     # NameError: Nama ≠ nama

20. Gaya penamaan yang umum

Python umumnya memakai gaya snake_case:

nama_lengkap = "Rian Indra"
tanggal_lahir = "2008-01-01"
jumlah_barang = 10
harga_barang = 5000

Lebih mudah dibaca dibanding namalengkap.

10 ÷ 3 → 3 × 3 = 9, sisa = 1

26. Menggabungkan string

Operator + juga berlaku pada string:

nama_depan = "Rian"
nama_belakang = "Indra"

nama_lengkap = nama_depan + " " + nama_belakang

print(nama_lengkap)     # Rian Indra

" " adalah string berisi satu spasi. Tanpa itu hasilnya RianIndra.

27. String dan angka tidak bisa langsung digabungkan

umur = 18
print("Umur saya " + umur)   # TypeError: str + int

Python tidak bisa melakukan str + int secara langsung.

28. Solusi: str()

umur = 18
print("Umur saya " + str(umur))     # Umur saya 18
angka = 100
teks = str(angka)
print(type(teks))     # <class 'str'>

29. Fungsi konversi tipe lain

str(100)         # "100"
int("100")       # 100
float("3.14")    # 3.14
angka = "100"
angka = int(angka)
print(angka + 20)     # 120

30. Hati-hati saat konversi

Tidak semua string bisa diubah menjadi angka:

int("Rian")     # tidak bisa, bukan representasi bilangan
int("3.14")    # bermasalah, "3.14" adalah bentuk desimal
float("3.14")  # lebih sesuai untuk nilai ini

31. print() bisa menerima beberapa nilai

print(nama, umur)          # Rian 18
print("Nama:", nama)       # Nama: Rian
print("Umur:", umur)       # Umur: 18

32. f-string

f-string adalah cara memasukkan nilai variabel ke dalam teks. Awalan huruf f di depan kutip menandakaninya, dan {nama} digantikan oleh nilai variabel nama.

nama = "Rian"
umur = 18

print(f"Nama saya {nama}")     # Nama saya Rian
print(f"Umur saya {umur}")     # Umur saya 18
nama = "Rian"
umur = 18
tinggi = 170.5

print(f"Halo, nama saya {nama}")
print(f"Saya berumur {umur} tahun")
print(f"Tinggi saya {tinggi} cm")

33. Variabel berdasarkan variabel lain

harga = 5000
jumlah = 3

total = harga * jumlah

print(total)     # 15000

34. Contoh sederhana sistem pembayaran

harga = 10000
jumlah = 2
uang = 30000

total = harga * jumlah
kembalian = uang - total

print(f"Total: {total}")
print(f"Kembalian: {kembalian}")

Program kecil ini sudah memakai variabel, int, operator matematika, dan f-string sekaligus.

37. Kesalahan yang umum terjadi

Kesalahan 1 — tanda kutip hilang

nama = Rian        # Python mencari variabel Rian
nama = "Rian"      # yang benar

Kesalahan 2 — tipe tidak cocok saat menghitung

umur = "18"
hasil = umur + 2       # str + int, tidak bisa

umur = 18
hasil = umur + 2       # 20

Kesalahan 3 — huruf besar tidak konsisten

Nama = "Rian"
print(nama)            # NameError, Python case-sensitive

Kesalahan 4 — spasi pada nama variabel

nama lengkap = "Rian Indra"       # salah
nama_lengkap = "Rian Indra"      # benar

38. Cara berpikir tentang variabel

Alih-alih menghafal nama = "Rian", jawab pertanyaannya: apa yang dilakukan kode ini?

nama = "Rian"      # Python membuat nama `nama` merujuk pada nilai "Rian"
print(nama)        # Ambil nilai yang dirujuk `nama`, lalu tampilkan
nama = "Andi"      # Assignment baru, `nama` kini merujuk pada "Andi"
